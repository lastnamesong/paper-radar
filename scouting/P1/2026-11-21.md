## 🥇 논문 1

**TacInno: Teaching Vision-Language-Action Models the Contact Dynamics Beyond Vision and Action**
[arXiv:2611.26405](https://arxiv.org/abs/2611.26405) · Weile Li, Yunfan Lou, Muqing Shi, Zihao Zhang, Zhenbiao Huang, Boxian Yao, Xiyu Zhu, Zhibo Pang · arXiv preprint · source: keyword-sweep

**점수 10/15** · R2 · N3 · M2 · Real3 · Repro0 — arXiv comment "Project page: https://tacinno.github.io" — 프로젝트 페이지뿐이고 코드 진술 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 촉각 변화 중 비전·행동이 설명 못 하는 부분만 학습 목표로 사용
- **문제** — 촉각을 붙인 VLA의 이득이 일관되지 않고 촉각 입력에 거의 의존하지 않는 정책이 생기는 일
  - 촉각 입력을 더해도 촉각 없는 동일 VLA보다 성공률이 낮아지는 경우가 있음
  - 촉각 센서는 로봇 자신의 행동에 대한 접촉 반응을 재므로 그리퍼 닫힘 중 젤 변형 같은 변화 상당 부분이 시각과 실행 행동으로 예측 가능
- **기존 한계** — 기존 비주오택타일 정책은 예측 가능한 촉각 변화까지 입력이나 목표로 그대로 사용
  - 촉각을 추가 입력으로 넣는 방식 — 예측 가능한 부분이 중복이라 성능이 오히려 떨어질 수 있음
  - 미래 촉각 신호를 예측하는 방식 — 예측 가능한 변화가 목표 대부분이라 손실이 비전·행동이 이미 설명하는 변화에 지배됨
  - 촉각 변화를 강조하는 학습 — 변화 크기로 손실에 가중해도 가장 큰 변화가 예측 가능한 변화라 도움이 안 됨
  - 촉각 입력을 제거하는 tactile-off 시험에서 일부 기존 정책의 성공률이 거의 변하지 않아 촉각 의존이 낮음
- **핵심 방법** — 비전·행동으로 설명되지 않는 잔차를 이산 코드로 압축하고 정책이 그 코드를 보조 목표로 예측
  - TacInno 토크나이저 — 초기 촉각 관측, 시각 관측, 실행 행동을 조건으로 인코더와 디코더를 구성해 미래 촉각 변화를 16비트 이산 코드로 압축
  - 짧은 촉각 시퀀스를 인과적 시간 어텐션으로 인코딩해 순간적 접촉 사건 포착
  - TacInno-VLA — 현재 관측에서 코드를 예측하는 보조 목적을 두어 행동 예측에 쓰는 촉각 표현을 지도
  - 배포 시 토크나이저와 보조 예측 헤드 제거
- **차별점** — 촉각 변화 전체가 아니라 잔차만 훈련 목표로 쓰고 배포 구조에 모듈을 더하지 않음
  - 코드는 훈련 목표로만 쓰이며 배포 시 추가 모듈 없음
  - 토크나이저 조건을 제거하면 성공률이 21%p 하락
- **핵심 기여** — 촉각 의존도 진단, 잔차 학습 목표, 시뮬레이션과 실물 검증
  - tactile-off 시험 — 일부 기존 정책이 촉각에 거의 의존하지 않음을 보임
  - 시뮬레이션 — UniVTAC 6개 과제 평균 87.5%, 가장 강한 비주오택타일 기준선 대비 10.7%p 우위
  - 실물 — Franka FR3와 비전 기반 촉각 센서 4개 과제 평균 70.5%, 가장 강한 기준선 대비 9.0%p 우위
  - 기준선 — 5개 비주오택타일 정책과 촉각 없는 π0.5
  - ablation — 시각·행동 조건, 다중 프레임 창, 어텐션 마스크, 촉각 분기와 코드 예측 손실을 분리
  - 의존도 — Lift Can 성공률이 촉각 제거 시 88%에서 0%로 하락하고 코드가 촉각 변화 전체를 담으면 들기 과제에서 21%p 하락
- **가치** — 촉각을 입력 모달리티가 아니라 훈련 신호로 쓰는 경로를 제시하고 저자는 다른 모달리티로의 확장을 후속 과제로 언급

### (c) 시사점

- 비전 기반 촉각 VLA에서 촉각의 훈련 목표 전용 사용 근거 확보
- 배포 모델에 촉각 처리 모듈이 늘지 않아 추론 구조 변경 비용 낮음
- tactile-off 시험은 촉각 융합 정책의 실제 촉각 의존도를 재는 공개 가능한 점검 절차
- 실물 4개 과제 정량 결과로 입력 융합 기준선 대비 우위 수치 확보
- 반응형 촉각 제어기와의 비교는 없음

### (d) 먼저 확인할 점

- 코드 저장소나 공개 약속 없이 프로젝트 페이지만 있음
- 촉각 제거 시험은 들기 과제 2개 중심이며 모든 과제에서의 의존도는 별도 확인 필요
- 실물에서 코드 예측 손실 제거(47.5%)와 촉각 입력 제거(51.5%)가 비슷해 이득이 코드 예측 손실에 한정됨
- 실물은 비전 기반 젤 센서 한 종류이며 배열형 센서로의 전이는 미검증
- 시뮬레이션과 실물 모두 반복 시드 분산 보고는 본문 확인 불가

## 🥈 논문 2

**Which Taxels, Not How Many: Tactile Sensor Placement for Dexterous Policies**
[arXiv:2611.10647](https://arxiv.org/abs/2611.10647) · Taeyun Kim, Jinsoo Shin, Taehwa Kim, Taeyoon Kim, Jinyoung Choi · arXiv preprint · source: keyword-sweep

**점수 8/15** · R2 · N3 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4TM](https://img.shields.io/badge/D4TM-d97706.svg)](#ref-D4TM)

### (b) 논문 요지

- 소수 taxel을 접촉 통계로 고르면 균일 배치 대형 세트와 동급
- **문제** — 시뮬레이션 촉각 연구가 taxel을 손 전체에 균일 배치하는 기본값을 검증 없이 쓰는 일
  - 접촉하지 않는 taxel도 관측 차원과 시뮬레이션 시간을 쓰고 실물 손에서는 배선과 읽기 대역폭을 차지
  - 정책이 어디에 접촉할지는 학습 전에 알 수 없음
- **기존 한계** — 기존 연구마다 배치와 인코더 선택이 달라 효과를 비교하기 어려움
  - 균일 배치는 측정된 요구가 아니라 가정이라고 저자가 지적
  - 파지에서는 공간 해상도 촉각이 손가락별 순 힘 이상을 더하지 않지만 인핸드 회전에서는 접촉 위치가 성능을 크게 높인다는 선행 결과가 있어 과제별 요구가 다름
- **핵심 방법** — 교사 정책, 학습 절차, 후보 taxel을 고정하고 센서 구성과 표현만 바꾸는 단일 통제 프로토콜
  - 후보 taxel — 과제에 쓰이는 링크 표면에 포아송 디스크 샘플링으로 2,000개를 균일 배치
  - 배치 방법 — 후보 중 예산 B(10–300)개를 고르는 4개 방법과 1개 통제군을 같은 후보 집합에서 비교
  - 선택 기준 — 교사 정책의 접촉 통계를 쓰는 Top-contact, Contact-cover, Link-proportional과 과제 정보가 없는 Uniform, 최소 접촉 지점을 고르는 Least-contact
  - 표현 — 인코더와 입력 텐서 내 taxel 배열을 바꿔 비교하며 CNN, LSTM, 링크별 MLP를 사용
  - 교사-학생 증류로 학생 정책 학습
- **차별점** — 센서 수가 아니라 어떤 taxel을 감지하느냐를 변수로 삼아 균일 배치를 측정 가능한 설계 선택으로 바꿈
  - 같은 교사·학습·후보 집합 아래에서 배치 기준과 표현만 바꿈
- **핵심 기여** — 배치와 표현에 대한 세 가지 설계 교훈과 보고 항목
  - 소수 taxel을 접촉 통계로 고르면 훨씬 큰 균일 세트의 성공률에 도달
  - 접촉이 드문 지점의 taxel은 촉각 입력 없음과 같고 최소 접촉 지점 배치는 한 번도 성공하지 못함
  - 모든 후보 taxel을 쓰면 입력 텐서 배열은 CNN에서도 성능에 영향 없고 인코더가 taxel 식별 정보를 보존해야 함
  - 인핸드 회전과 3종 로봇 손의 파지에서 평가하며 3개 시드의 평균과 표준편차 보고
  - 촉각 정책 연구가 보고할 최소 설계 선택 목록 제시
- **가치** — 촉각 정책 연구에서 센서 배치 결정과 보고 기준을 비교 가능한 형태로 제공

### (c) 시사점

- 배열형 촉각 설계에서 taxel 수보다 배치 위치가 핵심이라는 정량 근거 확보
- 접촉 통계로 학습 전에 배치를 정할 수 있어 센서 설계 비용 절감 가능
- 입력 텐서 배열보다 taxel 식별 정보 보존이 중요해 인코더 선택 기준 확보
- 실물 결과가 없어 비전 기반 센서와의 비교 근거는 아님

### (d) 먼저 확인할 점

- 모든 결과가 시뮬레이션이며 센서 잡음과 드리프트의 영향은 미검증
- 코드 저장소나 공개 약속 없음
- 교훈은 접촉이 소수 링크에 집중된 인핸드 회전 한 손 기준이며 접촉이 여러 링크에 퍼진 파지에서는 배치 효과가 다른 경향
- 접촉 통계는 교사 정책에서 얻으므로 다른 정책이나 인간 시연의 통계로 배치를 고를 수 있다는 점은 저자의 제안이며 본문 검증 아님
- 아키텍처가 아닌 센서 배치 비교라 비전 기반 센서와 배열 센서의 우열 판단에는 쓰이지 않음
