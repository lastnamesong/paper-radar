## 🥇 논문 1

**Tacinf: A Unified Tactile Infrastructure for Robot Manipulation**
[arXiv:2611.29240](https://arxiv.org/abs/2611.29240) · Qiwei Wu, Xiangyu Chen, Xin Xiang, Rui Zhang, Yihang Kang, Weiran Chen, Zikang Xie, Yangfan Li, Tao Wang, Xiangzheng Wang, Tianyi Bi, Zhiyan Zhang, Xianpeng Wang, Mingqian Zhou, Yan Yu, Chuanyu Li, Wenjie Zhang, Tao Li, Weihua Zhang, Renjing Xu, Junjie Lai · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R2 · N3 · M3 · Real3 · Repro1 — 초록 "are releasing the full stack as open source" — 저장소 URL 없음, 공개 약속만

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 힘 지시를 따르는 촉각 정책의 데이터·평가·배포 통합 스택
- **문제** — 로봇이 과제 문맥과 촉각 피드백에서 적절한 상호작용 힘을 추론해야 하는 힘 인식 조작
  - 힘 요구는 "gently"·"firmly" 같은 지시로 명시되거나 용기 열기·닦기처럼 암묵적으로 주어짐
  - 하드웨어와 센서 설계가 달라 촉각 데이터셋 수집 비용이 큼
  - 성능이 낮은 정책은 물체나 로봇을 손상시킬 수 있어 저비용 평가 플랫폼이 필요
- **기존 한계** — 원문에 대비 대상 언급 없음
- **핵심 방법** — 데이터 생성·정책 학습·수집 하드웨어·sim-to-real 평가를 네 모듈로 묶은 오픈소스 스택
  - Tacinf-Tabero — 촉각 관측과 힘 지도를 담은 시뮬레이션 데이터 생성과 VTLA 정책 벤치마크
  - Tacinf-VTLA — 정책별 촉각 인터페이스를 갈아 끼우는 모듈형 구조, 과제 언어·비전·촉각에서 행동과 손끝 힘을 함께 예측
  - Tacinf-Tacumi — 로봇 배포와 같은 그리퍼를 쓰는 핸드헬드 수집 하드웨어, 텔레오퍼레이션과 손에 든 시연으로 촉각 관측과 힘 목표를 수집
  - Tacinf-Taco — 과제 정렬 sim-to-real 평가와 다중 소스 데이터 증강·공동 후학습
  - 지시문에 힘 수준을 선택적으로 지정
- **차별점** — 원문에 대비 대상 언급 없음
- **핵심 기여** — 다중 소스 촉각 데이터 수집, 힘 제어 실행, 시뮬레이션-실물 정합
  - 다중 소스 데이터 — 저비용 오픈소스 수집 시스템, 데이터 피라미드의 결합 효과를 제거 실험으로 평가
  - 힘 제어와 실행 — 정책 예측에서 구동까지 잇는 시스템, 접촉 집약적 과제용
  - 시뮬레이션만으로 미세조정한 촉각 파운데이션 모델이 실물에 제로샷 이전, LIBERO 유사 과제 성공률 98% 이상
  - 정책 변형 8종에서 시뮬레이션과 실물의 성공률 순위가 일치, Pearson r=0.998, MMRV=0.010
  - 측정 파지력이 firm 지시에서 gentle 지시보다 큼, 힘이 보고된 정책 4종 모두 과제 3개 양쪽 영역에서 성립
  - 텔레오퍼레이션·시뮬레이션·Tacumi 혼합 데이터로 위치와 물체를 모두 무작위화한 실물 성공률 20%에서 60%
  - Tacumi 키트 2,500달러 미만, 최소 연산 요구는 RTX 4090 한 장
- **가치** — 힘 수준을 언어로 지정하는 촉각 정책을 시뮬레이션에서 평가하고 실물로 옮기는 공개 기준 스택 제시
  - 실물 로봇 없는 수집과 시뮬레이션 평가로 촉각 정책 개발 비용 절감

### (c) 시사점

- 촉각 정책 비교를 한 백본·한 프로토콜에서 돌리는 공개 평가대
- **비교 축** — 촉각 입력 방식과 힘 지도·피드백 실행을 같은 조건에서 분리 측정
  - 힘 지도 없는 변형은 gentle 성공률 0.01, 촉각 관측 없이 힘 지도만 쓴 변형은 gentle 0.45와 firm 0.82
  - 마커 필드 입력이 firm·gentle 균형이 가장 좋았고 힘 지도가 주된 성능 이득
- **도입 비용** — 키트 2,500달러 미만, 단일 RTX 4090
  - 저장소 URL 없이 공개 약속만 있어 실제 입수 시점 불명
- **데이터 전략** — 손에 든 시연은 단독으로 실패하나 다른 소스와 섞으면 위치 변화 보강원으로 기능

### (d) 먼저 확인할 점

- **규모 한계** — 저자들이 데이터셋과 과제 규모가 자원 제약으로 작고 대규모 학습은 평가하지 않았다고 명시
- **비교 조건** — 기존 설계를 공통 백본과 프로토콜 안에서 재구현한 변형이라 원 논문 수치와 직접 비교 불가
- **실물 컨트롤러 시험 규모** — 조건당 10회 시행, 과제 3개
  - 닫힌 루프를 끄면 칠판 닦기는 0으로 하락, 카드 긁기는 7점에서 3점
- **단일 소스 한계** — 손에 든 시연만으로는 firm 성공률 0%
- **공개 상태** — 저장소 URL 없음, 공개 예정 문구뿐
- **가장 싼 확인** — 공개 시 우리 센서에서 힘 지도 없는 변형과 있는 변형의 gentle 성공률 차이부터 재현

## 🥈 논문 2

**FORTH: Grounding Tactile VLA Execution via Forward-Only Proxy-Control Pairing**
[arXiv:2611.26744](https://arxiv.org/abs/2611.26744) · Junde Li, Wei-Han Yu, Xiangyi Chu, Yaoxin Li, Jiawei Xu, Ka-Fai Un, Pui-In Mak · arXiv preprint · source: keyword-sweep · 코드 공개

**점수 10/15** · R2 · N3 · M3 · Real0 · Repro2 — arXiv comment "The code and models are open-sourced at https://github.com/Jordanlllll/FORTH"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 역전파 없이 촉각 VLA를 갱신하고 슬립에 반응하는 제어 하네스
- **문제** — 촉각 VLA의 힘 제어 성능이 층별 대리 손실로만 보고돼 물체가 실제로 버티는지 알 수 없는 일
  - 대리 손실 최소화가 물리적 힘 접지를 뜻한다는 가정이 검증되지 않음
  - 물체 생존을 좌우하는 물리량이 함께 측정·보고되지 않음
- **기존 한계** — 각 연구 흐름이 자기 알고리즘 지표만 보고하고 물리량과 짝짓지 않음
  - 층별 지역 학습 목적 — 순전파만 쓰지만 성능을 지역 손실값으로만 보고
  - 영차(ZO) 최적화 — 역전파 메모리를 순전파 질의로 대체하나 추정 기울기 방향 정합만 평가
  - 하위 수준 컨트롤러 — 물리적 슬립을 이진 분류 목표로 다뤄 검출 정확도로만 채점
  - 기존 벤치마크 프로토콜 — 짝지어진 동역학을 체계적으로 측정하지 않음
- **핵심 방법** — 각 실행 수준마다 최적화 목표를 대응하는 물리 관측량과 짝지어 보고하는 하네스, 두 지표가 함께 움직일 때만 해당 수준을 수용
  - 촉각 특징 트렁크 — Forward-Forward 블록 2개로 구성, 전역 역전파 없이 접촉 기하를 보존
  - 토큰 병렬 영차 어댑터 — 랭크 8, 행동 헤드에 부착, 업데이트당 순전파 16회(T=8 토큰)
  - SlipGuard — 단일 클래스 전단비 게이트와 제한된 실시간 보정기, 초기 슬립에서 발화
  - 고정된 4비트 백본 위에서 전체가 순전파·층 지역 방식으로 동작
- **차별점** — 새 대형 백본이 아니라 측정 규약과 엣지 배포용 실행 계층을 내세움
  - 알고리즘 지표와 물리량을 같은 보고 단위로 묶는 짝 지표 규약
- **핵심 기여** — 하네스와 세 수준의 결과
  - 순전파 전용 촉각 트렁크가 역전파 표현 정확도와 같은 수준
  - 영차 어댑터의 최대 활성 메모리가 역전파 한 스텝 대비 7.12배 감소
  - 탄소성 구조 셸에서 SlipGuard의 최대 파지력이 단조 반사 램프보다 29배 낮고, 램프는 영구 변형을 남김
  - LIBERO 3개 스위트 평균 성공률 97.6%로 최고 수준과 대등하다고 보고
  - 견고성 — 위반 지속시간 5–150 ms와 힘 여유 1.1–2.5의 4×4 격자에서 SlipGuard가 160/160 회복, 일정 힘 정책 68/160, 질량·마찰을 아는 오라클 145/160
  - 골판지 상자에서 SlipGuard 0.250 N 대 반사 램프 22.00 N
- **가치** — 촉각 VLA의 힘 제어를 알고리즘 지표가 아닌 물리량으로 점검하는 규약 제시
  - 메모리가 작은 엣지 장치에서 촉각 정책을 갱신하는 길

### (c) 시사점

- 반응형 슬립 게이트가 일정 힘·반사 램프보다 얼마나 낫다는 비교 기준점
- **비교 축** — 슬립 시점에 파지력을 올리는 반응형 보정을 단조 램프와 오라클에 맞댄 결과
  - 단조 램프 대비 물체 손상을 1.59–3.42배 줄였다고 보고
  - 센서 교체 쌍 실험에서 12/12 회복, 이산 게이트 1/12, 수동 팔 0/12
- **도입 비용** — 저장소와 모델 공개, 4비트 백본에서 순전파만 사용
- **측정 규약** — 우리 평가에도 대리 지표와 물리량을 짝지어 보고하는 방식 이식 가능

### (d) 먼저 확인할 점

- **실물 로봇 결과 없음** — 파지력 결과는 결정론적 기판 위 시뮬레이션이고 LIBERO도 시뮬레이션
- **임계값의 성격** — 실센서 기록에서 경험적으로 보정한 값이라 센서별 오프셋에 따라 이동
  - 실센서 기록의 사전 발화 오탐률은 힘 통계 0.024, 비율 통계 0.031
- **기준선 성격** — 비교 대상 램프는 3 N/s로 22 N 상한까지 오르는 개루프 단조 램프
  - 다른 반응형 컨트롤러와의 비교는 아님
- **정책 성능과의 분리** — 97.6%는 LIBERO 벤치마크 수치라 촉각 입력 효과와 별개
- **가장 싼 확인** — 우리 센서의 실제 슬립 기록으로 전단비 임계값을 보정해 오탐률 측정

## 🥉 논문 3

**VeriTouch: Verified Visuo-Tactile World Models that Improve Robot Policy Learning**
[arXiv:2611.30572](https://arxiv.org/abs/2611.30572) · Shuxun Wang, Xiaonan Jiang, Zhaoyu Wang, Ziyuan Chu, Xihang Yue, Pengfei Liu, Haodong Zhu, Shiqi Liu, Mingzhi Zheng, Liang Su, Linchao Zhu · arXiv preprint · source: keyword-sweep

**점수 10/15** · R2 · N3 · M2 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 시각·촉각을 함께 생성하고 검증해 거른 합성 시연으로 정책 강화
- **문제** — 시각촉각 정책 학습용 실물 데이터는 비싼 촉각 센서와 노동집약적 원격조작이 필요
  - 시뮬레이션은 현실적 환경과 정확한 물성 모델링이 필요
  - 영상 합성에 촉각을 더하려면 보이는 접촉과 동기화된 그럴듯한 촉각 응답을 만들어야 함
- **기존 한계** — 합성 롤아웃·시뮬레이션·검증 방식 모두 비용이나 검증 범위에서 빈 곳이 남음
  - 반복 증강 — 데이터 생성과 정책 재학습을 여러 라운드 반복해야 함
  - 시뮬레이션 기반 방식 — 추가 환경이 필요해 데이터 생성 비용과 복잡도 증가
  - 기존 검증 — 특정 오류는 잡으나 전체 시연에 걸친 촉각 그럴듯함과 시각 접촉과의 시간 정렬을 함께 평가하지 못함
- **핵심 방법** — 생성기, 검증기, 행동 추출기를 잇는 합성 시연 파이프라인
  - VeriGen — 사전학습 비디오 백본에 전용 촉각 전문가를 붙인 세계 모델, 교차 시점 어텐션으로 장면 문맥과 근접 접촉 세부를 결합해 이중 시점 영상과 촉각 시퀀스를 함께 생성
  - VeriEval — 촉각 재구성 오차와 과제별 접촉력을 평가하고 시각·촉각 접촉 구간의 시간 정렬을 점검하는 멀티모달 검증기
  - VeriIDM — 두 카메라의 전역 장면 정보와 그리퍼 세부, 이웃 프레임 움직임으로 검증된 영상에서 행동 추출
- **차별점** — 반복 재학습과 시뮬레이션 재생 없이 생성 직후 촉각·시각 정합을 거름
  - 시각 필터링만 쓰는 방식과 갈리는 점은 촉각 그럴듯함과 접촉 시간 정렬을 검증에 넣은 것
- **핵심 기여** — 파이프라인, 검증기, 실물 5개 과제 결과
  - 실물 5개 과제(chip pick, egg pick, charger press, pullback car, whiteboard erase)에서 정책 4종 모두 향상, 평균 성공률 실제 데이터만 19.4%에서 33.8%
  - 합성 데이터를 실제의 4배로 늘리면 평균 성공률 33.0%에서 67.0%
  - 검증 없는 합성 데이터는 평균 22.9%에 그침
  - 시각만 거른 경우 43.3%, 멀티모달 검증은 51.7%, 검증 없음 33.3%
  - 합성 촉각 관측을 무접촉 입력으로 바꾸면 51.7%에서 26.0%
- **가치** — 생성 모델로 시각촉각 데이터를 늘릴 때 양보다 신뢰할 수 있는 궤적 선별이 중요하다는 점 제시
  - 실물 시연을 더 모으지 않고 정책 성능을 키우는 경로

### (c) 시사점

- 촉각 시연 부족을 합성과 검증으로 메우는 실물 확인 사례

  - 촉각을 뺀 합성 데이터는 26.0%로 떨어져 합성 촉각의 기여가 큼
- **적용 범위** — 비전 정책 2종과 시각촉각 정책 2종 모두 향상
- **도입 비용** — 사전학습 비디오 백본 위 세계 모델 학습 필요
