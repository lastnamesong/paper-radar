## 🥇 논문 1

**ForceHarness: Turning Force into Action and Physics for Frozen Frontier Models**
[arXiv:2611.21099](https://arxiv.org/abs/2611.21099) · Ke Sun, Kevin Yuchen Ma, Yike Zhang, Yanzhe Chen, Mike Zheng Shou · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R3 · N2 · M3 · Real3 · Repro1 — §J.2 "Code and configurations will be released upon publication, together with logs and task assets."

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 고정 API 모델에 힘 제어와 물리량 번역층을 얹은 하네스
- **문제** — 이미지로 보이지 않는 접촉 힘이 필요한 조작을 가중치가 고정된 API 모델이 풀지 못하는 일
  - 나사 조이기, 겉보기가 같은 병의 무게 비교처럼 힘이 핵심인 과제
  - 접촉은 API 모델의 결정 속도보다 빠르게 변하고, 원시 힘 신호는 모델이 해석하지 못함
- **기존 한계** — 힘을 다루는 기존 방식은 학습에 기대거나 모델에 원시 수치를 넘김
  - 힘 인지 정책과 벤치마크 — 손목 힘을 시각운동 정책과 VLA 입력으로 추가하며 과제마다 시연이 필요하고 가중치를 갱신하므로 API 전용 고정 모델에 적용 불가
  - 접촉을 노출하는 기존 하네스 — 원시 렌치·촉각 값을 그대로 넘기거나 힘 제어 코드를 모델이 생성하게 해 보정된 물리 피드백 없이 모델이 수치 해석과 저수준 제어를 떠안음
- **핵심 방법** — 모델과 로봇 사이에 세 겹의 층을 둔 하네스
  - 힘 감지·보정층 — 손목 센서 또는 관절 토크만으로 손의 힘을 추정하고 센서 오프셋 제거
  - 자기 종료 힘 프리미티브 — 가드 이동, 슬라이딩, 삽입 등을 호출형 도구로 만들어 호출 후 스스로 힘을 조절하고 접촉 이벤트에서 반환
  - 물리 번역층 — 힘 궤적을 질량, 접촉 높이, 마찰 같은 물리량으로 바꿔 불확실도와 상태 플래그와 함께 도구 결과로 반환
  - 매 턴 모델이 프리미티브를 호출하고 반환된 물리량을 읽어 다음 행동 결정
- **차별점** — 힘 루프를 모델 아래에서 닫고 모델에는 해석된 물리량만 반환
  - 시연이나 미세조정 없이 고정 모델이 힘을 쓰는 점이 힘 인지 정책과 갈림
- **핵심 기여** — 하네스, 벤치마크, 실물 및 시뮬레이션 검증
  - 하네스 — 힘 보정, 자기 종료 프리미티브, 물리 번역의 세 층
  - HiddenPhys — 숨은 물리 변수를 가진 MuJoCo 7개 과제 벤치마크, 전문가 힘 제어기와 학습 정책을 동일 시드로 평가
  - 실물 — 손목 힘 센서 없는 팔의 6개 과제에서 GPT-6 Astra 제로샷 성공률 3.3%에서 90.0%로 상승, 60회 중 2회에서 54회
  - 시뮬레이션 — 공개 ForceBench 70.0%에서 87.5%, HiddenPhys 62.1%에서 96.4%로 상승해 과제당 약 200개 시연으로 학습한 Diffusion Policy, π0.5, ForceVLA를 상회하고 전문가 제어기와 동등
  - ablation — 힘 프리미티브, 피드백 형태, 결정 루프를 HiddenPhys에서 분리했고 작은 모델일수록 원시 힘 값보다 물리량을 받을 때 결정이 나음
- **가치** — 학습 없이 API 전용 모델에 힘 감각을 붙이는 경로 제시

### (c) 시사점

- 힘 제어를 모델 아래에 두고 해석된 물리량만 위로 올리는 구조의 정량 근거 확보
- 고정 모델 하네스가 시연 학습 힘 인지 정책을 ForceBench와 HiddenPhys에서 상회한다는 대비 수치 확보
- 손목 센서 없이 관절 토크 추정만으로 실물 6개 과제를 푼 점은 센서 추가 비용 없는 도입 후보
- 손끝 촉각을 다루는 논문이 아니며 손목 힘 수준의 결과

### (d) 먼저 확인할 점

- 코드는 공개 예정 문구뿐이고 저장소 URL 없음
- 모델 질의가 프리미티브 사이에 수 초를 더해 반응형 협응을 배제한다고 저자가 명시
- 고정된 프리미티브 메뉴가 새로운 운동 법칙을 제한한다고 저자가 명시
- ablation은 시뮬레이션에서만 수행, 실물 평가는 조건당 10회 시행
- 결과가 특정 상용 API 모델 버전에 의존하므로 다른 모델에서의 재현 확인 필요

## 🥈 논문 2

**TMA: Sim-to-Real Forceful Humanoid Manipulation via Tactile-Driven Motor Adaptation**
[arXiv:2611.18976](https://arxiv.org/abs/2611.18976) · Yiting Chen, Kelin Yu, Sarthak Kaingade, Bryan Trinh, Kaiyu Hang, Roberto Martin-martin, Nima Fazeli, X. Alice Wu · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M3 · Real2 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 촉각 이력으로 모터 행동을 적응시켜 문손잡이를 여는 휴머노이드
- **문제** — 휴머노이드의 다지 조작이 형상 중심에 머물러, 접촉 역학이 성패를 좌우하는 힘 집약 과제를 못 푸는 일
  - 둥근 문손잡이는 손가락의 접촉 방식, 수직력 분배, 마찰 토크, 미끄러짐 회피가 성패를 결정
  - 마찰과 내부 기구 동역학은 비전과 고유수용감각으로 관측되지 않아, 안정 파지와 임박한 미끄러짐이 비슷한 관측을 냄
- **기존 한계** — 순간 촉각 반응이나 고유수용감각 이력만으로는 접촉 상태가 구분되지 않음
  - 반응형 촉각 정책 — 순간 접촉에는 반응하나 같은 접촉력이 이전 상호작용에 따라 다른 마찰 여유를 뜻하는 점을 구분하지 못함
  - Rapid Motor Adaptation(RMA) — 실행 중 쌓인 관측으로 환경을 추정해, 역구동이 안 되는 손에서는 접촉력 변화가 관절 변위로 드러나지 않음
  - 형상 중심 휴머노이드 조작 — 접촉이 형성되는 위치와 움직임에 의존하고 접촉의 물리 상태를 조절하지 않음
- **핵심 방법** — 촉각 상호작용을 중심으로 정책을 구성하고 최근 촉각 이력으로 모터 행동을 온라인 적응
  - 상호작용 구조화 보상 — 촉각으로 관측되는 상호작용을 기준으로 정책 학습 구성
  - 접촉 중심 촉각 표현 — 원뿔 기하로 촉각 신호를 매개변수화해 다지 접촉을 접촉 역학에 근거시킴
  - 촉각 구동 모터 적응 — 최근 촉각 상호작용 이력에서 적응 인코더가 잠재 상태를 추정해 행동 조절
  - 상체 조작 정책을 사전학습된 범용 보행 제어기와 함께 학습해 전신 안정화와 협응
  - 정책과 적응 인코더는 강화학습과 지도 잠재 회귀로 시뮬레이션에서만 학습
- **차별점** — 이력 조건 적응 구조는 유지하되 적응 근거를 실행 중 우연히 쌓인 관측에서 능동 접촉으로 일부러 얻은 촉각 반응으로 옮김
  - 접촉이 행동의 인터페이스이면서 숨은 물리 속성을 드러내는 센싱 수단이라는 이중 역할
- **핵심 기여** — 벤치마크 과제, 적응 프레임워크, 통합 시스템
  - 둥근 문손잡이 열기를 상호작용 지배형 다지 휴머노이드 조작의 벤치마크로 제안
  - TMA — 시뮬레이션만으로 학습해 Unitree G1과 BrainCo Revo2 다지 손에 제로샷 이전
  - 시판 문손잡이 4종에서 손잡이당 10회 시행, 미세조정 없이 RMA와 반응형 촉각 정책 베이스라인을 상회, 본문에는 수치 대신 막대 그림으로 제시
  - 저자 주장으로는 다지 손을 쓴 휴머노이드의 이 과제 첫 시연
  - 보행 제어기와 결합한 전신 통합 시스템
- **가치** — 비전과 고유수용감각으로 보이지 않는 접촉 상태를 촉각 이력으로 추정해 힘 집약 다지 조작을 시뮬레이션에서 실물로 옮기는 경로 제시

### (c) 시사점

- 순간 촉각 반응과 촉각 이력 적응을 실물에서 맞댄 대비 확보
- 이진 접촉 피드백만 받는 반응형 정책이 파지는 만들어도 과제 완수에 실패한다는 관찰 확보
- 시뮬레이션 학습 후 제로샷 실물 이전이라 실물 시연 수집 비용 없음
- 학습된 정책 입력으로서의 촉각 이력과 비전-촉각 융합의 직접 비교는 논문이 다루지 않음

### (d) 먼저 확인할 점

- 코드 저장소 없음, 프로젝트 페이지만 존재
- 실물 평가는 한 종류의 과제와 Unitree G1 한 기종, 손잡이당 10회 시행이라 성공률의 신뢰 구간이 넓음
- 촉각 신호, 시간 문맥, 상호작용 목표의 추가 ablation은 저자가 향후 과제로 명시
- 지문 패드 손상 후 성능이 크게 떨어진다고 저자가 명시, 마찰 한계가 곧 성능 한계
- 반응형 베이스라인이 이진 접촉 신호만 받아 연속 힘을 쓰는 반응형 제어기와의 대비는 아님

## 🥉 논문 3

**TaF-Foundation: Wrench-Grounded Cross-Sensor Tactile Representations**
[arXiv:2611.20718](https://arxiv.org/abs/2611.20718) · Jiaming Jiang, Yuzhe Huang, Baokun Yang, Hao Liang, Li Gao, Haoran Guo, Pei Lin, Shengcheng Luo, Chenxi Xiao, Wanlin Li, Ziyuan Jiao · arXiv preprint · source: keyword-sweep

**점수 11/15** · R2 · N3 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4TM](https://img.shields.io/badge/D4TM-d97706.svg)](#ref-D4TM) [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 6차원 렌치를 공통 기준으로 센서 간 촉각 표현 학습
- **문제** — 센서마다 감지 원리와 관측 형식이 달라 촉각 데이터를 센서와 과제 사이에 재사용하기 어려운 일
  - 따로 수집된 촉각 데이터셋에는 접촉 상태를 센서 간에 비교할 공통 물리 기준이 없음
  - 처음 보는 센서 하드웨어로의 일반화가 충분히 탐구되지 않음
- **기존 한계** — 기존 촉각 표현 학습은 센서 다양성과 규모가 제한적
  - 공유 구조 자기지도 학습 — 재사용 가능한 특징의 공통 틀은 주나 센서 간 정렬은 다루지 않음
  - 센서 간 정렬 방법 — 같은 접촉 조건에서 모은 촉각 쌍이 필요
  - 접촉의 힘 관련 속성에 표현을 근거시킨 선행 시도 — 센서 다양성과 규모가 제한적
- **핵심 방법** — 센서별 입력 적응과 공유 인코더로 렌치를 복원하며 표현을 접촉 물리에 근거시킴
  - 센서별 입력 어댑터가 서로 다른 관측 형식을 토큰으로 변환
  - 공유 트랜스포머가 학습 가능한 물리 질의로 토큰을 집계
  - 모멘텀 갱신 렌치 인코더의 목표와 정렬하고 공유 디코더로 측정 렌치를 복원
  - TaF-Policy — 촉각 특징, 시각 관측, 로봇 상태를 합쳐 행동 청크 생성
- **차별점** — 센서마다 독립적으로 실측 렌치와 짝지어 센서 쌍 간의 직접 대응 없이 공유 물리 지도 신호 확보
  - 센서 간 정렬 방법이 요구하던 같은 접촉 조건의 공동 수집이 불필요
- **핵심 기여** — 데이터 인프라, 통합 표현, 벤치마크와 조작 정책
  - 광학, 자기, 압력, 압저항 4개 계열 24개 센서에서 1억 개 넘는 촉각-렌치 쌍을 모은 수집 플랫폼과 데이터
  - 단일 프레임 힘 RMSE 2.799N에서 2.321N으로 17.1% 감소, 센서 간 검색 R@1 21.27%에서 34.38%로 13.11%p 상승, 지표별 최강 베이스라인 대비
  - 시뮬레이션 UniVTAC 3개 과제 평균 성공률 51.3%, 최강 베이스라인 47.3%
  - 실물 4개 과제 평균 46.25%, 최강 베이스라인 23.75%이며 초록 기준 수치
  - 처음 보는 센서에 대한 소수 샷 적응 평가와 정렬 손실, 센서별 MLP ablation
- **가치** — 서로 다른 촉각 센서를 한 물리 기준 위에서 재사용하는 표현의 기반 제시

### (c) 시사점

- 비전 기반 센서와 어레이 센서를 가리지 않는 센서 불문 촉각 인코더의 공개 기준점 후보
- 1억 쌍 규모의 촉각-렌치 데이터가 센서 선택을 데이터 규모 문제와 분리해 비교하는 근거
- 촉각 특징을 시각·상태와 융합하는 정책의 실물 이득 수치 확보
- 융합 정책과 반응형 제어기의 직접 대비는 논문이 다루지 않음

### (d) 먼저 확인할 점

- 코드·데이터 공개 언급 없음, 프로젝트 페이지만 존재
- 처음 보는 센서 적응에도 라벨된 촉각-렌치 쌍과 센서별 입력 모듈 학습이 필요하다고 저자가 명시
- 정밀 정렬이나 안정 파지가 필요한 과제에서 신뢰도가 낮다고 저자가 명시, 열쇠 삽입은 정렬 어긋남, 병 들기는 파지 불안정과 미끄러짐으로 실패
- 시뮬레이션 이득은 4.0%p로 작고, 실물 과제 수 표기가 초록 4개 과제와 본문 3개 공통 과제로 갈려 읽을 때 구분 필요
- 반복 시드는 표현 벤치마크에만 있고 조작 평가는 과제당 20회 시행
