## 🥇 논문 1

**TF²-Steering: Action Refinement with Tactile Forecasts and Feedback via Velocity-Field Steering**
[arXiv:2611.01483](https://arxiv.org/abs/2611.01483) · Yiming Chen, Xiaofei Wei, Chun Gu, Wei Xiao, Peidong Liu, Li Zhang · arXiv preprint · source: keyword-sweep

**점수 10/15** · R3 · N2 · M2 · Real3 · Repro0 — arXiv comment "Project page: https://yiming-cc.github.io/tf2-steering/" — 프로젝트 페이지만, 코드 문장 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- 촉각 예측과 실시간 피드백으로 행동 속도장을 보정
- **문제** — 시각 위주 기초 정책에 촉각을 넣는 방법과 촉각의 역할 정립
  - 촉각 신호의 시간적 희소성과 촉각 데이터의 적은 규모로 시각 우세 정책이 촉각 단서를 무시하거나 사전학습 표현을 해침
  - 촉각을 피드백으로만 쓸지 예측으로도 쓸지 미정리
- **기존 한계** — 잔차 경로와 게이팅 방식이 촉각 기여를 약하게 만듦
  - 잔차 경로 — 별도 학습한 보정 가지가 이미 생성된 행동만 수정, 차선 계획을 바꾸는 데 한계
  - 게이팅 — 백본은 보존하나 학습된 게이트가 행동 헤드 도달 전 촉각 특징을 감쇠
  - 반응형 촉각 피드백 연구와 미래 촉각 예측 연구가 하나의 인과적 행동 보정 과정으로 통합되지 않음
- **핵심 방법** — 흐름 매칭(flow matching) 행동 전문가의 속도장에 촉각 전문가가 델타 속도를 더하는 이중 주기 구조
  - 촉각 전문가 — 행동 전문가 특징을 단방향으로 참조하며 촉각 예측과 실시간 촉각 피드백으로 델타 속도 산출, 행동 전문가는 촉각 입력 없이 독립 유지
  - 촉각 월드 모델 — 가용한 월드 맥락에서 미래 촉각 상태 예측
  - 이중 주기 — 영상·촉각 월드 모델은 저주기 계획 사전분포, 행동·촉각 전문가는 고주기 보정, 예측은 행동 블록 전 한 번 생성해 실행 중 고정
  - 3단계 학습 레시피로 촉각 예측과 예측·실시간 촉각의 활용을 지원
- **차별점** — 촉각 입력을 받지 않는 원래 행동 전문가를 그대로 두고 속도장 수준에서만 촉각 보정
  - 생성된 행동 사후 수정이 아니라 생성 과정 내부 보정
  - 원래 행동 전문가를 독립된 기본 행동원으로 계속 사용 가능
- **핵심 기여** — 이중 주기 프레임워크, 속도장 스티어링 알고리즘, 시뮬레이션·실물 평가
  - 시뮬레이션 6개 과제 평균 성공률 68.3%, 최강 베이스라인 FTP-1 대비 10.6%p 상회
  - 시뮬레이션 Insert Hole 94.0%, 최강 베이스라인 56.0%
  - 실물 6개 과제 평균 진행 성공률 71.5%, 최강 베이스라인 T-Rex 대비 9.1%p 상회
  - 촉각 예측, 실시간 피드백, 속도장 스티어링 각각의 기여를 보이는 ablation
- **가치** — 촉각 데이터가 적어도 시각 기초 정책의 사전학습 능력을 지키며 접촉 집약적 조작에 촉각을 얹는 경로 제시

### (c) 시사점

- 촉각 융합 대 보정 경로의 직접 비교 근거 확보
- 촉각 이미지를 π0.5에 그대로 추가하면 시뮬레이션 평균 56.0% 대 55.7%로 거의 불변
- 같은 직접 추가가 실물에서는 40.2%에서 35.2%로 하락
- 촉각을 시각 기초 정책에 붙이는 후보 설계로 검토 가치
- 촉각 센서 없는 설정으로의 일반화는 논문이 직접 다루는 쟁점이 아님

### (d) 먼저 확인할 점

- 코드 저장소 없음, 프로젝트 페이지만 존재
- 반복 시드와 한계 서술은 확인되지 않음
- 실물 평가는 진행 성공률(progress success rate) 기준이며 과제당 20회 시행
- 실물 플랫폼 하나(양팔 UR5e와 Sharpa 22-DoF 손), 다른 손·센서 이전은 미검증
- 촉각 이미지 합성 입력이 사전학습 구성과 달라 분포 이동을 일으킨다는 설명은 저자 가설

## 🥈 논문 2

**TactileLab: Sim-to-Real Dexterous Robot Manipulation with Efficient Shear-Sensitive Tactile Simulation**
[arXiv:2611.07881](https://arxiv.org/abs/2611.07881) · Yijiong Lin, Wenhao He, Toby Jack, Max Yang, Haoran Li, Nathan F. Lepora · arXiv preprint · source: keyword-sweep · 코드 공개 예정

**점수 12/15** · R2 · N3 · M3 · Real3 · Repro1 — §I "TactileLab will be released as an open-source framework"

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D4TM](https://img.shields.io/badge/D4TM-d97706.svg)](#ref-D4TM)

### (b) 논문 요지

- 강체 시뮬레이션만으로 전단 촉각 흐름을 만드는 촉각 시뮬레이터
- **문제** — 전단이 중요한 접촉 집약적 조작을 대규모 강화학습으로 학습할 효율적 촉각 시뮬레이션 부재
  - 비전 기반 촉각 센서는 고해상도 공간 관측을 주지만 접선 방향 상호작용의 확장 가능한 시뮬레이션이 어려움
  - 깊이 신호만으로는 비슷한 깊이가 서로 다른 접촉 상태에 대응해 과제가 부분 관측이 됨
- **기존 한계** — 촉각 시뮬레이터 두 갈래 모두 전단 학습에 불충분
  - 연체(soft-body) 시뮬레이터 — 순응 접촉을 높은 충실도로 모사하나 대규모 강화학습에는 느림
  - 강체 시뮬레이터 — 빠르고 확장 가능하나 대개 깊이형 신호만 제공해 전단·미끄러짐·접선 운동 과제에 약함
  - 최근 분산 법선·전단 모사는 기하 의존 접촉식과 물체별 전처리에 의존
- **핵심 방법** — IsaacLab 기반 GPU 병렬 시뮬레이터에서 접촉 깊이 장과 시뮬레이션 촉각 흐름을 함께 제공
  - 시뮬레이션 촉각 흐름 — 탄성체 변형을 모사하지 않고 강체 시뮬레이션에서 접촉면의 조밀한 접선 변위 장을 직접 계산
  - PETS-Net — 장기 고유수용감각 이력과 고차원 촉각 관측을 함께 인코딩하는 정책 구조
  - 실-시뮬레이션 촉각 변환 — 접촉 깊이와 촉각 흐름 각각의 변환기, 실제 촉각 이미지 스트림에서 시뮬레이션 촉각 흐름 예측
- **차별점** — 접촉 기하·물체별 전처리 가정 없이 강체 시뮬레이션에서 전단 단서를 직접 계산
  - 정적 단일 촉각 이미지 변환을 동적 접선 운동 표현으로 확장
- **핵심 기여** — 시뮬레이터, 촉각 모달리티, 환경 묶음, 정책 구조, 변환 방법, 실물 배치
  - 접촉 힘, 접촉 위치, 접촉 깊이 이미지, 시뮬레이션 촉각 흐름을 지원하는 다중 모달 촉각 시뮬레이션 프레임워크
  - 단일 팔, 양팔, 다지 인핸드 조작을 포함한 접촉 집약적 환경 묶음
  - 양팔 물체 추종과 인핸드 물체 조작 두 과제의 상세 시뮬레이션 연구
  - 시뮬레이션만으로 학습한 정책을 세 물체 집합에서 평가, 인핸드 회전 1.95 ± 0.81회
  - GelSight Mini, TacTip, 9DTact 세 센서에 걸친 실-시뮬레이션 촉각 변환 검증
  - 양팔 물체 추종과 인핸드 조작의 실물 배치
  - 오픈소스 프레임워크 공개 예정
- **가치** — 이종 촉각 센서에 걸친 전단 감응 조작 정책의 대규모 시뮬레이션 학습 경로 제시

### (c) 시사점

- 비전 기반 촉각 센서의 시뮬레이션 학습 비용 절감 가능성
- 센서 세 종을 하나의 촉각 표현으로 묶는 변환 근거 확보
- 센서 선택을 비전 기반 쪽으로 기울일 때 재현 가능한 학습 환경 후보
- 어레이·e-skin 센서와의 대조는 논문이 다루지 않음

### (d) 먼저 확인할 점

- 코드 공개는 약속 단계, URL 없음
- 실-시뮬레이션 변환이 탄성체가 물체 표면에 달라붙은 접촉(no-slip)을 전제하며, 외란이나 급격한 접촉 변화에서 복구 불가 상태 가능성을 저자가 명시
- 강체 시뮬레이션의 근사이므로 연체 시뮬레이터 대비 충실도는 낮음
- 다양한 물체 형상으로 확장하려면 더 큰 고차원 실-시뮬레이션 데이터와 기하 인식 변환 모델 필요

## 🌱 논문 3 — 인접 분야 픽

**Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs**
[arXiv:2611.05249](https://arxiv.org/abs/2611.05249) · Asher James Hancock, Boyi Li, Yuxiao Chen, Shuhan Tan, Wenhao Ding, Thomas Tian, Yan Wang, Boris Ivanovic, Marco Pavone · adjacent field: VLA 아키텍처 전반

**점수 7/15** · R2 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P1](https://img.shields.io/badge/P1-f5e9d5.svg)](#ref-P1) / [![D7VT](https://img.shields.io/badge/D7VT-d97706.svg)](#ref-D7VT)

### (b) 논문 요지

- VLM 단절 학습의 이득은 행동 토큰 지도 여부에 좌우
- **문제** — 행동 전문가의 손실로 VLM을 함께 학습할지 막을지에 대한 근거 부족
  - VLM은 행동 전문가의 흐름 매칭 목적으로 학습된 적이 없으나 그 표현이 제어에 쓸모 있어야 함
  - 연속 행동 예측 목적에 맞는 이산 대리 지도 정의는 영역 의존 설계라 실험으로 확인 필요
- **기존 한계** — 단절(insulation) 이득이 다른 요소와 얽혀 분리되지 않음
  - Knowledge Insulation — FAST 행동 토큰과 시각·언어 목적을 함께 쓴 단절 학습의 이득을 보고, 행동 토큰 없는 단절은 평가하지 않음
  - Wall-OSS-0.5 — 이산 행동·멀티모달 목적을 유지하고도 결합(coupling) 학습이 더 강한 행동 성능
  - 두 결과는 학습 레시피, 초기화, 데이터, 최적화가 달라 행동 토큰 지도와 기울기 흐름의 기여를 가르지 못함
  - 시각·언어 공동 학습이 망각을 막는다면 단절의 추가 보호 효과도 불분명
- **핵심 방법** — 행동 토큰 지도 유무와 전문가에서 VLM으로의 기울기 흐름 유무를 교차한 통제 실험
  - 자율주행과 로봇 조작 두 영역에서 수행
  - 동시 학습과 한 요소를 먼저 적응시키는 학습 일정 둘 다 비교
  - 같은 일정과 행동 토큰 설정 안에서 데이터, 구조, 최적화, 의미 공동 학습 고정
- **차별점** — 행동 토큰 지도를 기울기 경로와 분리해 독립 변수로 통제
- **핵심 기여** — 행동 토큰 지도가 기울기 경로 효과와 얽힌 요인임을 보인 실험 결과
  - 개루프 주행 — 행동 토큰 지도가 있으면 결합과 단절이 거의 구분되지 않고, 없으면 결합이 궤적 예측 오차를 약 25% 감소
  - 폐루프 주행 동시 학습 — 결합이 경로 진행률을 행동 토큰 지도 있을 때 약 17%, 없을 때 40% 향상
  - 시뮬레이션 로봇 조작 — 두 설정 모두에서 결합이 과제 진행 향상
  - 결합 단계 학습은 행동 토큰 지도 아래에서 관측된 과실 충돌률이 더 높음
- **가치** — 단절을 기본 VLA 학습 레시피가 아닌 조건부 선택으로 재고하게 하는 근거 제시

### (c) 시사점

- 촉각 스트림을 VLA에 융합할 때 VLM 기울기 경로 설계를 고려할 근거
- 행동 토큰 지도의 존재가 기울기 차단의 이득을 바꾼다는 점이 촉각 융합 학습 일정 설계에 참고
- 촉각 자체를 다룬 논문이 아니어서 촉각 입력 아래에서 같은 결과가 유지되는지는 별도 확인 필요

### (d) 먼저 확인할 점

- 폐루프 평가는 시뮬레이션 주행과 시뮬레이션 조작뿐이며 실물 로봇 검증 없음
- 주행 모델 계열 하나와 조작 모델 계열 둘만 연구, 구조 다양성 제한
- 조건당 학습 1회라 학습 시드 변동 미측정, 부트스트랩 구간은 평가 클립 변동만 반영
- 성능 차이의 기전은 확립하지 않은 경험적 연구
- 촉각 조건 실험 없음, 촉각 융합으로의 이전은 가설 단계
