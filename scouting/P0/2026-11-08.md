## 🥇 논문 1

**Where Does EEG Help Wearable Freezing of Gait Detection?**
[arXiv:2611.00497](https://arxiv.org/abs/2611.00497) · Chuntian Chi, Lifang He, Huajie Shao, Gang Zhou · arXiv preprint · source: keyword-sweep

**점수 8/15** · R3 · N2 · M3 · Real0 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6KM](https://img.shields.io/badge/D6KM-d97706.svg)](#ref-D6KM)

### (b) 논문 요지

- EEG를 입력과 사전학습에 각각 써 보고 IMU 보행 동결 검출 향상 위치를 비교
- **문제** — 다리가 거의 멈춘 구간에서 IMU 기반 보행 동결(FoG) 검출 신뢰도 하락
  - 무동성 동결, 의도적 정지, 서 있기, 느린 회전이 비슷한 다리 신호를 만들어 오경보 발생
- **기존 한계** — IMU 검출기는 다리 떨림이 있는 동결에서만 안정적
  - 3–8 Hz 다리 떨림을 쓰는 freezing index 계열은 다리가 거의 멈추면 구분 근거를 잃음
  - EEG 기반 검출기는 실험실 성능은 높으나 모자와 피부 접촉이 필요해 일상 모니터링에 비실용적
- **핵심 방법** — 동일 데이터·폴드·평가에서 사전학습 모달리티와 검출기 입력 모달리티만 달리한 6개 설정 비교
  - EEG와 IMU 동시 기록 코퍼스 5개 데이터셋 184명 94시간으로 사전학습
  - 설정별 하이퍼파라미터 탐색과 독립 사전학습 5회 수행
  - IMU 인코더를 EEG와 정렬해 배포 시 IMU만 쓰는 경로(특권 정보 방식)를 EEG 입력 경로와 대조
- **차별점** — EEG를 추론 입력으로 쓸 때와 사전학습에서만 쓸 때를 같은 조건에서 분리 비교
  - 효과가 나타나는 구간을 다리 움직임 사분위별로 분해
- **핵심 기여** — 통제된 비교 결과와 코퍼스 의존성 분석
  - BXHC 데이터셋(환자 단위 leave-one-patient-out, FoG 환자 10명)에서 EEG 입력 시 FoG F1 0.663에서 0.740으로 상승, 10명 중 9명 개선
  - 순위 성능 향상은 다리 움직임이 가장 적은 사분위 창에 한정(AUROC +0.063)
  - EEG 공동 사전학습한 IMU 단독 검출기는 동일 코호트에서 F1 0.663에서 0.705, 소규모 코호트 학습 후 타 코호트 시험에서 F1 +0.083(시험 환자 10명 전원 개선)
  - PD 단독·건강인 단독 코퍼스 반복에서 IMU 검출은 코퍼스에 강건하나 EEG 정렬 이득은 두 집단 모두 필요
  - 외부 3개 데이터셋 PD 대 비PD 분류에서 걷기 EEG 기준 AUROC 0.750 대 0.683
  - 의도적 정지를 주석하지 않은 검출기는 거의 모든 정지를 동결로 분류
- **가치** — 일상 착용이 어려운 EEG를 학습 단계에서만 쓰고 IMU 단독으로 배포하는 경로의 근거 제시

### (c) 시사점

- IMU 단독 검출기의 약점 구간에 한해 보조 모달리티 가치 확인
- 모달리티 선택
  - IMU를 앵커로 두고 EEG는 사전학습 보조로 쓰는 안의 실측 근거 확보
  - 이득이 다리 정지 구간에 집중되어 IMU 검출기 평가를 움직임 수준별로 쪼개 볼 필요
- 데이터 관점
  - 의도적 정지 주석 유무가 교차 코호트 성능을 좌우해 자체 데이터 수집 시 주석 규약 선행 필요

### (d) 먼저 확인할 점

- 실물 로봇 결과 없음, 착용 센서와 환자 데이터 평가만 수행
- 라벨 코호트가 작음(FoG 환자 10명과 4명)
  - SenseFOG 결과는 유의성이 아닌 방향성 수준, 4명이면 Wilcoxon p 하한 0.125
- 코드 저장소와 공개 약속 없음
- 정지 구간 이득이 피질 활동 때문인지 근활동이나 잔여 움직임 때문인지는 아티팩트 통제 분석 필요
- 코호트 간 동결 하위 유형, 의도적 정지, 약물·자극 상태, EEG 전처리 차이가 교차 코호트 결과에 한꺼번에 섞임

## 🥈 논문 2

**Multi-Agent Reinforcement Learning of Co-Adaptive Hip Exoskeleton Control (MARL-Exo) for Metabolic Energy Reduction**
[arXiv:2610.37441](https://arxiv.org/abs/2610.37441) · Yifei Yuan, Jakob Wolf, Ghaith Androwis, Xianlian Zhou · arXiv preprint · source: keyword-sweep

**점수 11/15** · R2 · N3 · M3 · Real3 · Repro0 — 초록·arXiv comment·본문 모두 코드 저장소나 공개 약속 없음

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D3WA](https://img.shields.io/badge/D3WA-d97706.svg)](#ref-D3WA)

### (b) 논문 요지

- 시뮬레이션 공동적응 학습 고관절 외골격 정책을 재학습 없이 착용자에 적용
- **문제** — 외골격 착용자가 수동적 대상이 아니라 보조에 맞춰 근육 동원을 바꾸는 점
  - 토크를 걸면 보행 역학이 바뀌고 제어기는 계속 적응하는 착용자에 맞춰 조정되는 상태
  - 보조 목적함수에 따라 효과가 크게 달라져 착용자 반응을 잘 반영하는 목적이 필요
- **기존 한계** — 사람 대상 최적화와 기존 시뮬레이션 학습 모두 한계
  - 휴먼 인 더 루프 최적화는 사용자·조건마다 긴 실험 반복 필요
  - 사람과 기기를 동시에 학습하면 서로의 데이터 분포를 흔들어 진동성 토크, 어긋난 타이밍, 발산 위험
  - 보상의 노력 항이 근활성이나 일 같은 대리 지표, 사용자가 체감하는 대사 에너지는 정책 보상 항으로 쓰이지 않음
  - Exo-Plore는 단순화한 활성 가중 에너지식, Barati 등은 대사 목적을 인간 모델에만 적용하고 외골격 보상에는 활성 기반 항 사용
- **핵심 방법** — 전신 인체 모델과 양측 고관절 외골격 정책을 2단계로 동시 학습하는 다중 에이전트 강화학습
  - 인체 모델 근육 액추에이터 304개, 체형·보행·속도 무작위화
  - 1단계 인체 단독 보행, 2단계 공동 적응
  - 외골격은 의도적으로 지연한 고관절 운동학과 직전 명령만 관측, 저가 웨어러블 센싱으로 구동 가능
  - 보상에 생리 기반 근육 에너지 모델의 대사 파워 포함, 단독(Metabolic) 또는 기계적 파워 정형 병용(Metabolic + Power)
- **차별점** — 근육 에너지 모델의 대사 파워를 외골격 정책 보상 항으로 직접 사용
  - 이전 SMAT(26근육 4단계 커리큘럼) 대비 전신·체형 집단 모델로 확장
- **핵심 기여** — 시뮬레이션 비교와 실기 검증
  - 시뮬레이션에서 Metabolic 정책이 무장치 보행 대비 모델 대사 파워 13.8% 감소, Metabolic + Power는 8.8%
  - 건강한 성인 8명 하드웨어 시험(1.25 m/s, 간접열량측정)에서 Passive 대비 순 대사율 18.3 ± 6.6% 감소, 8명 전원(보정 p<0.001)
  - 무장치(No-Exo) 대비 평균 7.4 ± 10.0% 감소, 착용 페널티 13.1%를 8명 중 6명이 상쇄하고 최대 24.2% 아래
  - 고관절 가동범위 36.8% 확대, 추정 보조 파워의 98.5%가 양(+)
- **가치** — 사용자별 튜닝 없는 집단 단위 제어기와 인체 시험 전 시뮬레이션 목적 선별 경로 제시

### (c) 시사점

- 사용자별 튜닝 없이 시뮬레이션 학습 정책을 실기에 옮긴 정량 선례
- 구동 쪽 선택
  - 센싱을 지연된 고관절 운동학으로 최소화한 구동 중심 접근의 실측 근거
  - 기계적 파워 정형이 시뮬레이션 이득을 오히려 줄인 결과는 보조 목적 설계의 참고점
- 하드웨어와 동일 8명 코호트로 선행 연구와 이어져 후속 비교 가능

### (d) 먼저 확인할 점

- 코드·체크포인트 공개 진술 없음
- 8명 건강 성인 단일 속도(1.25 m/s) 평가
  - 무장치 대비 평균 감소 7.4 ± 10.0%로 개인 편차 큼, 2명은 착용 페널티를 상쇄하지 못함
- 연조직 순응과 스트랩 느슨함이 잔여 한계로 서술되며 12 N·m 하드웨어 토크 상한이 결과에 영향
- 환자군·경사·속도 변화 결과 없음, 이전 SMAT 평가와 같은 기기·코호트라는 점 고려 필요

## 🌱 논문 3 — 인접 분야 픽

**From Pixels to Actions - Towards Native Vision-Language-Action Policies**
[arXiv:2611.06918](https://arxiv.org/abs/2611.06918) · Weichen Fan, Haiwen Diao, Penghao Wu 외 · adjacent field: VLA architecture advances broadly · 코드 공개

**점수 12/15** · R2 · N2 · M2 · Real3 · Repro3 — arXiv comment "Code link: https://github.com/EvolvingLMMs-Lab/NEO/tree/main/VLAKit"

### (a) 관련 Pillar / Decision

[![P0](https://img.shields.io/badge/P0-f5d5d5.svg)](#ref-P0) / [![D6KM](https://img.shields.io/badge/D6KM-d97706.svg)](#ref-D6KM)

### (b) 논문 요지

- 비전 인코더 없이 픽셀을 직접 토큰화하고 여러 깊이에서 행동을 읽는 VLA
- **문제** — 행동 예측이 최종 시각 표현만 받아야 하는지, 중간 시각 연산도 직접 받아야 하는지
  - 조작은 국소 기하, 경계, 깊이, 미세한 상태 변화 같은 압축에 취약한 신호에 좌우
- **기존 한계** — 기존 VLA는 사전학습 인코더(CLIP, SigLIP, DINOv2)가 압축한 특징을 언어 백본과 행동 모델로 전달
  - 인코더 출력만 노출하고 그것을 만든 시각 계층은 숨김
  - 시각 처리가 VLA 성능에 결정적이고, 시각 구성요소가 가지치기에 민감하며, 행동 미세조정이 사전학습 시각 표현을 훼손한다는 선행 근거를 제시
- **핵심 방법** — 경량 합성곱 패치 임베더가 픽셀을 토큰으로 바꿔 언어와 한 백본에서 함께 처리
  - 플로우 매칭 행동 전문가가 백본의 여러 층 캐시 키·값을 읽어 연속 행동 청크 예측
  - 읽는 층을 초기·후기·다중으로 바꿔 시각 읽기 깊이를 정책 선택지로 노출
- **차별점** — 분리된 인코더 없이 구조적으로 인코더 없는 백본을 쓰고 행동 전문가가 여러 깊이에 접근
  - 인코더 기반 백본에서 중간 시각 특징으로 라우팅해도 이득이 재현되지 않음(동결 시 79.5%에서 64.9%)
- **핵심 기여** — 구조, 읽기 깊이 연구, 벤치마크와 실물 평가
  - 동일 행동 전문가·로봇 학습 코퍼스로 Qwen3-VL-2B, Gemma-3-4B와 비교, 백본 동결 LIBERO 평균 90.9% 대 79.5%, 84.5%, 전체 미세조정 95.3%
  - 초기 층을 포함한 읽기가 후기 층 단독보다 우수하고 초기 층 활성 교체가 후기 층 교란보다 예측 오차를 크게 키움
  - LIBERO 평균 97.4, LIBERO-plus와 RoboTwin 2.0에서 분포 변화에 강건
  - 실물 3개 과제 성공 12/20, 17/20, 13/20으로 π0.5와 같거나 우수하고 StarVLA를 크게 상회
  - 저자들은 사전학습과 모델 규모 차이로 이득을 인코더 제거만으로 돌릴 수 없다고 명시
- **가치** — 행동 정책이 인코더 출력 하나가 아니라 계산 계층 전반에 접근해야 한다는 설계 원리 제시

### (c) 시사점

- 인코더 없이 원입력을 백본이 직접 처리하는 공개 기준점 확보
- 의도 추정 모달리티 관점
  - IMU·EMG 원신호를 토큰으로 직접 받고 중간 층에서 읽는 구조로 옮길 때의 후보 설계
  - 최종 특징만 쓰는 방식 대비 초기 층이 행동에 유리하다는 결과는 센서 신호 인코더 설계의 가설
- 코드와 가중치 공개로 도입 비용 낮음

### (d) 먼저 확인할 점

- 시각 입력 기반 조작 정책이며 웨어러블·IMU·EMG 신호에 대한 검증 없음, 이월 효과는 가설 단계
- 비교 대상과 사전학습·모델 규모가 달라 인코더 제거 효과를 단독 귀속 불가(저자 명시)
- 반복 시드나 한계 서술 확인되지 않음
- 실물 평가는 단일 로봇(pika)의 3개 과제, 과제당 20회 시행으로 규모 작음
- 표준 벤치마크 비교는 설정이 달라 통제 비교가 아님(저자 명시)
